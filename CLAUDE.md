# Instruções para Claude

Siga `AGENTS.md` e `README.md` antes de alterar este repositório. O fluxo permanente é branch de tarefa → `main` → `homolog` → `production`. `production` é a única branch ligada ao hosting de produção.

Banco, RLS, RPCs e contratos compartilhados pertencem a `arenadigital-db`. Não faça commit, push, merge, deploy ou mudança de configuração externa sem autorização explícita.
